# Timecode Builder — จับคู่ภาพกับเสียงให้ตรงวินาที

สร้าง Timecode Map · ชื่อไฟล์ภาพ · ซับสะอาด · ตำแหน่ง mid-roll จากไฟล์เสียง + สคริปต์ต้นฉบับ

## หลักการเดียวที่ต้องจำ

> **เวลาเอาจาก SRT · ตัวหนังสือเอาจากสคริปต์ต้นฉบับ**

SRT ที่ได้จากเครื่องมือถอดเสียง (SayToWords, Whisper) มีเวลาแม่นแต่**ตัวหนังสือเพี้ยนเสมอ**สำหรับภาษาไทย ตัวอย่างจริงที่เจอ: เศษกระจก→เสกกระจก · ทุ่งหญ้า→ทุ่งย่า · ขวางเลน→ขวางเล่น · นักประสาทวิทยา→นับภาษาวิทยา

**ห้ามเอาข้อความจาก SRT ไปใช้** ทั้งที่เรามีบทอยู่ในมือแล้ว

## Input ที่ต้องขอจากผู้ใช้

1. **ไฟล์เสียงที่มาสเตอร์เสร็จแล้ว** (ไฟล์เดียว ต่อสมบูรณ์แล้ว)
2. **ไฟล์ SRT** ของไฟล์เสียงนั้น — ถ้าไม่มี ใช้ silence detection แทนได้ (ดูท้ายเอกสาร)
3. **สคริปต์ต้นฉบับ .txt** แบ่งย่อหน้าด้วยบรรทัดว่าง

**ถ้าผู้ใช้ซอยเสียงเป็นหลายไฟล์** ต้องต่อให้เสร็จก่อนถอด SRT เสมอ ห้ามถอดแยกแล้วบวกเลขเอง เพราะเวลาจะคลาดกับไฟล์จริงที่เอาไปตัด

## ขั้นตอน

### 1. อ่าน SRT

```python
import re
segs=[]
for b in re.split(r'\n\s*\n', open(SRT,encoding="utf-8").read().strip()):
    L=[x for x in b.split("\n") if x.strip()]
    if len(L)<3: continue
    m=re.match(r'(\d+):(\d+):(\d+),(\d+) --> (\d+):(\d+):(\d+),(\d+)',L[1])
    h,mn,s,ms,h2,mn2,s2,ms2=map(int,m.groups())
    segs.append([h*3600+mn*60+s+ms/1000, h2*3600+mn2*60+s2+ms2/1000, " ".join(L[2:])])
for i in range(len(segs)-1): segs[i][1]=max(segs[i][0]+0.3, segs[i+1][0])
DUR=segs[-1][1]
```

### 2. จับคู่สคริปต์กับ SRT ด้วย anchor — ขั้นที่สำคัญที่สุด

**อย่าใช้สัดส่วนตัวอักษรล้วน ๆ** เพราะคนพูดไม่ได้เร็วคงที่ และ ASR ตกคำไม่สม่ำเสมอ วิธีนั้นทำให้ภาพเลื่อนจากเสียงได้ถึง **5 วินาที** ในช่วงกลางคลิป

ใช้การหาข้อความที่ตรงกันเป๊ะเป็นจุดยึดแทน:

```python
import bisect
script="".join(re.sub(r'\s','',p) for p in paras)      # สคริปต์ ตัดช่องว่างออก
srt_txt="".join(re.sub(r'\s','',t) for _,_,t in segs)  # SRT ตัดช่องว่างออก

anchors=[]; last=0
for sp in range(0, len(script)-12, 6):
    w=script[sp:sp+12]
    k=srt_txt.find(w, last)
    if k!=-1: anchors.append((sp,k)); last=k
```

คลิป 10 นาทีปกติจะได้ประมาณ **800–900 จุดยึด** ซึ่งพอให้แม่นระดับ **ต่ำกว่า 0.5 วินาที**

จากนั้นแปลงตำแหน่งตัวอักษรใน SRT → เวลา โดยเทียบสัดส่วนภายใน segment ที่ตัวอักษรนั้นตกอยู่

### 3. ยึดช็อตสำคัญเข้ากับย่อหน้า

ระบุช็อตที่มีจุดสังเกตชัด (ชื่อนักวิจัย · ข้อความบนจอ · ประโยคพลิก) แล้วผูกกับย่อหน้าที่มันอธิบาย ประมาณ **40–60 จุดต่อคลิป 10 นาที** แล้วกระจายช็อตที่เหลือระหว่างจุดยึด

### 4. ปรับความยาวช็อตให้สม่ำเสมอ

หลังคำนวณเวลา ให้เกลี่ยให้ทุกช็อตอยู่ในช่วง **1.6–4.2 วินาที** โดยไม่ขยับจุดยึด:

```python
MIN,MAX=1.6,4.2
for _ in range(400):
    for i in range(1,N):
        d=t[i]-t[i-1]
        if d<MIN:   need=(MIN-d)/2; t[i]+=need; t[i-1]-=need
        elif d>MAX: ex=(d-MAX)/2;   t[i]-=ex;   t[i-1]+=ex
```

### 5. ตั้งชื่อไฟล์ภาพ = เวลา

```python
def fn(t):
    t=round(t*2)/2                       # ปัดเป็นครึ่งวินาที
    h=int(t//3600); m=int((t%3600)//60); s=t%60; si=int(s)
    return f"{h:02d}_{m:02d}_{si:02d}{'_5' if abs(s-si-0.5)<1e-6 else ''}"
```

ได้ `00_02_18_5.jpeg` = ปรากฏที่นาที 2 วินาที 18.5 — ลากเข้า timeline แล้วเรียงถูกเองตามชื่อ

**ต้องกันชื่อซ้ำ** ถ้าซ้ำให้ขยับ +0.5 วินาทีจนไม่ซ้ำ

## จำนวนช็อต

```
จำนวนช็อต = ความยาวคลิป (วินาที) ÷ 2.6
```

วัดจากคลิปสารคดีระดับมืออาชีพได้ **2.5–2.7 วินาทีต่อภาพ** และ **95% ของเฟรมเป็นภาพนิ่ง** — สไลด์ตัดแข็งคือวิธีที่ถูกต้อง ไม่ต้องทำอนิเมชัน

**ถ้าผู้ใช้มีภาพชุดเดิมอยู่แล้วและอยากใช้ซ้ำ** ให้ล็อกจำนวนช็อตเท่าเดิม แล้วปรับความยาวเฉลี่ยแทน ภาพทุกใบยังใช้ได้ เปลี่ยนแค่ชื่อไฟล์

## ผลลัพธ์ที่ต้องส่งมอบ

**Timecode Map** — ตารางที่มีคอลัมน์ `# · ชื่อไฟล์ · In · Out · Dur · เสียงพูดว่า · ภาพต้องเป็น` การมีสองคอลัมน์สุดท้ายคู่กันทำให้ผู้ใช้ตรวจเองได้ทุกแถวว่าภาพตรงกับเสียงไหม

**ซับสะอาด (.srt)** — ใช้เวลาจาก SRT เดิม แต่ตัวหนังสือจากสคริปต์ ตัดบรรทัดที่ช่องว่างระหว่างคำเสมอ ห้ามตัดกลางคำหรือกลางจุดไข่ปลา แล้วลบบรรทัดว่างโดยรวมเข้ากับบรรทัดก่อนหน้า

**ตำแหน่ง mid-roll** — เลือกจุดที่ **เงียบยาว + อยู่ก่อนประโยคที่เปิดช่องว่างความอยากรู้** (ก่อนคำถาม ก่อนคำว่า "แต่...") คนดูจะทนดูโฆษณาเพราะอยากรู้ประโยคถัดไป · คลิป 10 นาทีใส่ 3 จุดกำลังดี · คลิปต้องยาวเกิน 8 นาทีถึงจะใส่ได้

**ตารางเปลี่ยนชื่อไฟล์ (.csv)** — `SHOT,filename,in,out,dur` เผื่อผู้ใช้ต้องจับคู่ภาพเองภายหลัง

## ถ้าไม่มี SRT

ตรวจจับช่วงหยุดหายใจจากคลื่นเสียงโดยตรง ไม่ต้องผ่าน ASR เลย:

```bash
ffmpeg -y -v error -i AUDIO -ac 1 -ar 16000 /tmp/_a.wav
ffmpeg -hide_banner -i /tmp/_a.wav -af "silencedetect=noise=-40dB:d=0.15" -f null - 2>&1 \
  | grep -o "silence_start: [0-9.]*\|silence_end: [0-9.]*" | sed 's/silence_//'
```

> `-v error` จะกลืน output ของ silencedetect ต้องใช้ `-hide_banner` แทน

แล้วเลือกจุดตัดที่ใกล้เป้า 2.6 วินาทีที่สุดจากกึ่งกลางของแต่ละช่วงเงียบ — ทุก cut จะตกบนลมหายใจจริง ไม่มีภาพเปลี่ยนกลางคำ ข้อเสียคือขอบประโยคหยาบกว่าใช้ SRT เล็กน้อย
