# Timecode และจังหวะ

## กฎเหล็ก

**เวลาเอาจาก SRT · ตัวหนังสือเอาจากสคริปต์ต้นฉบับ**

ASR ไทยอ่านผิดเสมอ ตัวอย่างจริง:

| ควรเป็น | ASR ได้ |
|---|---|
| เศษกระจก | เสกกระจก |
| ทุ่งหญ้า | ทุ่งย่า |
| ขวางเลน | ขวางเล่น |
| สิ่งกีดขวาง | สิ่งกิดขวาง |
| นักประสาทวิทยา | นับภาษาวิทยา |
| ความเสือก | ความเสื่อ |

## ชื่อไฟล์ภาพ = เวลา

`HH_MM_SS[_5].jpeg` เช่น `00_02_18_5.jpeg` = ปรากฏที่ 2:18.5
ลากเข้า timeline แล้วเรียงถูกเองตามชื่อ
