# .claude/memory — ความจำร่วมของทีม

ทุกอย่างในโฟลเดอร์นี้ **ถูก commit ขึ้น git** ใครดึงโปรเจกต์ไปก็ได้ความจำชุดเดียวกัน

## ทำไมต้องอยู่ตรงนี้

Claude Code เก็บความจำได้สองที่ — ระดับผู้ใช้ (`~/.claude/`) กับระดับโปรเจกต์ ระดับผู้ใช้อยู่แค่ในเครื่องคนเดียว ทีมไม่เห็น และหายไปเมื่อเปลี่ยนเครื่อง

โปรเจกต์นี้จึงบังคับให้ **ทุกความจำลงที่นี่ที่เดียว**

## วิธีเขียนความจำใหม่จากนี้ไป

**ก่อนเขียน ให้ถามตัวเองก่อนเสมอ:** "สิ่งนี้เป็นกฎ/ค่าคงที่/แพตเทิร์นที่คลิปต่อไปจะใช้ซ้ำได้จริงไหม หรือเป็นแค่สิ่งที่เกิดขึ้นกับคลิปนี้ตอนนี้"

- **ถ้าเป็นกฎ/ค่าคงที่/แพตเทิร์นที่ใช้ซ้ำได้** → เขียนแบบสรุปสั้นต่อท้ายไฟล์หลักที่ตรงหัวข้อที่สุด (ฟอร์แมตด้านล่าง) อย่าสร้างไฟล์ใหม่พร่ำเพรื่อ
- **ถ้าเป็นความคืบหน้าของคลิปที่กำลังทำอยู่** (เลือกหัวข้อ, เขียนบท, QC ภาพ, ประกอบ CapCut, thumbnail, อัปโหลด ฯลฯ) → เขียนลง `archive/clip-0XX-<slug>.md` โดยตรง (สร้างไฟล์ใหม่ทันทีที่เลือกหัวข้อคลิปนั้น ใช้เลขคลิปสามหลัก + slug ภาษาอังกฤษสั้น ๆ ของหัวข้อ) **ถ้าระหว่างทางเจอบทเรียนที่ทั่วไปพอจะใช้ซ้ำกับคลิปอื่นได้ ให้เขียนสรุปสั้น ๆ ไว้ในไฟล์หลักที่ตรงหัวข้อด้วย** (ไม่ต้อง copy รายละเอียดทั้งหมด แค่สรุปกฎ + ลิงก์กลับมาที่ archive ถ้าต้องการบริบทเต็ม)
- **ถ้าเป็นรอบเสนอหัวข้อ/เช็คตลาด/เช็ค Analytics** → เขียนลง `archive/topic-rounds.md` / `archive/market-watch-log.md` / `archive/analytics-log.md` ตามหมวด — เก็บเฉพาะ **insight ล่าสุดที่ยังใช้อยู่จริง** ไว้แบบสั้นในไฟล์หลัก (เช่น "แพตเทิร์นที่ยืนยันซ้ำหลายคลิป" ใน `channel.md`) ไม่ต้อง copy ตารางคะแนนเต็มมาไว้ในไฟล์หลัก

    **วันที่:** 2026-08-08
