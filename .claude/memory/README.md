# .claude/memory — ความจำร่วมของทีม

ทุกอย่างในโฟลเดอร์นี้ **ถูก commit ขึ้น git** ใครดึงโปรเจกต์ไปก็ได้ความจำชุดเดียวกัน

## ทำไมต้องอยู่ตรงนี้

Claude Code เก็บความจำได้สองที่ — ระดับผู้ใช้ (`~/.claude/`) กับระดับโปรเจกต์ ระดับผู้ใช้อยู่แค่ในเครื่องคนเดียว ทีมไม่เห็น และหายไปเมื่อเปลี่ยนเครื่อง

โปรเจกต์นี้จึงบังคับให้ **ทุกความจำลงที่นี่ที่เดียว**

## ไฟล์

| ไฟล์ | เก็บอะไร |
|---|---|
| `channel.md` | เอกลักษณ์ช่อง น้ำเสียง กลุ่มคนดู ตัวเลขที่วัดได้ |
| `audio.md` | ค่ามาสเตอร์เสียง ปัญหาที่เคยเจอ วิธีแก้ |
| `timecode.md` | ค่าคงที่เรื่องจังหวะ ความยาวช็อต การจับคู่เสียงกับภาพ |
| `images.md` | Style Bible ปัญหาที่ AI ชอบทำ วิธีกัน |
| `decisions.md` | การตัดสินใจที่ตกลงแล้ว พร้อมเหตุผล — กันการถกซ้ำ |

## วิธีเขียน

เขียนต่อท้ายไฟล์ที่ตรงหัวข้อที่สุด อย่าสร้างไฟล์ใหม่พร่ำเพรื่อ

รูปแบบที่อยากได้:

    ## หัวข้อสั้น ๆ

    ข้อสรุปหนึ่งประโยค

    **ที่มา:** วัดจากอะไร / เจอตอนไหน
    **วันที่:** 2026-08-08

เขียนเฉพาะสิ่งที่**จริงและวัดได้** อย่าเขียนความเห็นลอย ๆ ถ้าเป็นการเดา ให้ระบุว่าเดา

## เขียนเสร็จแล้ว

```bash
git add .claude/memory && git commit -m "memory: <สรุปสั้น ๆ>"
```
