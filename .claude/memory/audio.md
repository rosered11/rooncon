# เสียง

## ค่าเป้าหมาย

-14 ถึง -16 LUFS · LRA 2–3 · true peak ไม่เกิน -1.0 dBFS · แซมเปิลชนเพดาน 0

YouTube **หรี่คลิปที่ดังเกิน แต่ไม่ดันคลิปที่เบาให้ดังขึ้น** ส่งไปเบา = เสียเปรียบถาวร

## เชนที่ใช้จริงและผ่าน

```
volume=-3dB, alimiter=limit=0.891:level=disabled,
loudnorm=I=-14:TP=-1.2:LRA=3, alimiter=limit=0.85:level=disabled
```

ผลลัพธ์: -15.3 LUFS · LRA 2.2 · true peak -1.33 dBFS · clipped 0

**ที่มา:** `ElevenLabs_custom_v2_fixed.wav`
**วันที่:** 2026-08-06

## บทเรียน: alimiter ต้องมี level=disabled

ถ้าไม่ใส่ ตัวลิมิตจะดันความดังกลับขึ้นมาจน peak ทะลุอีก เสียเวลาไปหลายรอบกว่าจะเจอ

## บทเรียน: Limiter ต้องเป็นขั้นสุดท้ายเสมอ

เคยใช้ **Amplify** แทน Limiter หลัง Loudness Normalization ใน Audacity
ผล: true peak +0.29 dBFS · 4,164 แซมเปิลชนเพดาน กระจาย 2,051 ช่วง = เสียงแตกจริง

**ห้ามใช้ Amplify แทน Limiter เด็ดขาด**

**วันที่:** 2026-08-06

## ElevenLabs ทำ mastering ให้ไม่ได้

ไม่มี compressor ไม่มี limiter ไม่มีที่ตั้ง LUFS ทุกแพลน ส่งออกมาราว -23.5 LUFS คงที่
ต้องมาสเตอร์นอกเครื่องมือเสมอ ไม่มีทางลัด

v3 คือโมเดลเดียวที่รองรับไทย · ไม่รองรับ `<break>` tag · ช่อง TTS จำกัด 5,000 ตัวอักษร

## ช่วงหยุดที่เหมาะ

เฉลี่ย 0.33–0.40 วินาที · ยาวสุดไม่เกิน 0.95 วินาที
ช่วงที่ยาวเกิน 1 วินาทีคือรอยต่อบท **ห้ามตัดให้เท่ากับช่วงอื่น** ไม่งั้นฟังเหมือนอ่านรวดไม่มีวรรคตอน
