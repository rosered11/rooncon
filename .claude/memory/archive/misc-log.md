## สถานะ YPP: ยังไม่ผ่านการอนุมัติ (เช็คแล้ว 2026-08-09)

เข้าเมนู "การสร้างรายได้" (Monetization) ในวิดีโอจริงแล้ว **ไม่เจอเมนูนี้เลย** — ยืนยันว่าช่องยังไม่ผ่านการอนุมัติเข้า YouTube Partner Program (ไม่ว่าจะแบบ expanded หรือเต็มรูปแบบ) เมนูนี้จะไม่โผล่ในวิดีโอจนกว่าจะผ่านก่อน

**ผลกระทบต่อ pipeline:** Ad breaks (mid-roll) ตั้งไม่ได้เลยตอนนี้ทั้งคลิป 001, 002, 003 — คำนวณตำแหน่ง mid-roll ไว้ล่วงหน้าได้ตามปกติ (บันทึกใน `midroll_positions.md` ของแต่ละคลิป) แต่ต้อง**รอผ่าน YPP ก่อนแล้วค่อยย้อนกลับไปตั้งให้ครบทั้ง 3 คลิปทีเดียว** ผ่าน YouTube Studio → เลือกวิดีโอ → การสร้างรายได้ → ช่วงโฆษณา (Manual)

**วิธีเช็คความคืบหน้าการสมัคร:** เมนูซ้ายมือหลักของ Studio (ไม่ใช่ในวิดีโอ) → "การสร้างรายได้" จะเห็นหน้าความคืบหน้าเทียบกับเงื่อนไข expanded YPP (500 ผู้ติดตาม + 3 คลิปใน 90 วัน + 3,000 ชั่วโมงดูใน 12 เดือน — ดูหัวข้อ "เกณฑ์ YPP ที่เกี่ยวกับช่องนี้" ด้านบน)
