# คู่มืออัปโหลดคลิปแรก — ทีละหน้าจอ

ไฟล์ที่ต้องเตรียมไว้ข้าง ๆ:
- `คลิป.mp4`
- `output4_metadata.md` (ชื่อ + description + tags)
- `subtitle_th_clean.srt`
- ภาพ thumbnail 1280×720

---

## ⚠️ ก่อนเริ่ม — เช็ค 2 อย่าง

**1. ยืนยันเบอร์โทรแล้วหรือยัง**
Studio → Settings → Channel → Feature eligibility → **Intermediate features**
ถ้ายังไม่ผ่าน **จะอัป thumbnail เองไม่ได้** ต้องทำก่อน ใช้เวลา 2 นาที

**2. ตั้งค่าระดับช่องให้เรียบร้อย**
Studio → Settings → Channel → Advanced
- Country of residence: **Thailand**
- เลือก **"ไม่ ตั้งช่องนี้ไม่ได้ทำเพื่อเด็ก"** ← ตั้งที่ระดับช่องไว้เลย จะได้ไม่ต้องเลือกทุกคลิป

---

# หน้าที่ 1 — Details

เข้า `studio.youtube.com` → มุมขวาบนกด **CREATE** → **Upload videos** → เลือกไฟล์ MP4

> ระหว่างที่มันอัปโหลดอยู่ กรอกข้อมูลข้างล่างได้เลย ไม่ต้องรอ

### Title
```
คุณไม่ได้ใจร้าย — สมองคุณแค่กำลังซ้อมหนีตาย
```

### Description
คัดลอกทั้งบล็อกจาก `output4_metadata.md` **อย่าลืมใส่อีเมลติดต่องานแทน [อีเมล]**

> **สำคัญ:** ต้องมี `0:00` เป็นบรรทัดแรกของรายการเวลา และมีอย่างน้อย 3 บท แต่ละบทยาวเกิน 10 วินาที YouTube ถึงจะสร้าง chapters ให้ — ของคุณมี 13 บท ผ่านสบาย

### Thumbnail
กด **Upload file** เลือกภาพที่ทำไว้ (1280×720, ไม่เกิน 2MB)

**อย่าเลือกภาพนิ่งจากคลิป** ทั้งสามภาพที่ระบบเสนอมาไม่มีข้อความ จะแพ้คลิปอื่นในฟีดทันที

### Playlists
ยังไม่ต้องทำ รอมีคลิปที่สองค่อยสร้าง

### Audience — จุดที่ห้ามพลาด
เลือก **"ไม่ วิดีโอนี้ไม่ได้ทำเพื่อเด็ก"**

> เลือกผิดเป็น "ใช่" จะโดนตัดโฆษณาแบบ personalized (รายได้ตกฮวบ) · ปิดคอมเมนต์ · ปิดการแจ้งเตือน · ปิด end screen — และแก้ทีหลังก็ไม่ได้คืนยอดที่เสียไป

Age restriction: **ไม่ต้องจำกัด**

### กด "Show more" แล้วตั้งต่อ

**Altered content / AI use** → เลือก **No**

> การ์ตูนสติ๊กฟิกเกอร์ไม่เข้าเกณฑ์ "สมจริง" ที่ YouTube บังคับให้แจ้ง ส่วนเสียง TTS อยู่ในหมวดที่เอกสารเขาระบุว่าไม่ต้องแจ้ง

**Tags** → วางชุด tags จาก `output4_metadata.md`

**Language** → Video language: **ไทย**

**Category** → **Education**

**Comments** → เปิด · Sort by: **Top comments**
> คลิปนี้จบด้วยคำถาม คอมเมนต์คือสัญญาณ engagement ที่แรงที่สุดสำหรับคลิปแรก

**License** → Standard YouTube License

**Shorts remixing** → อนุญาต (ช่วยให้คนอื่นช่วยกระจายคลิปคุณ)

กด **NEXT**

# หน้าที่ 2 — Video elements

### Subtitles ← อย่าข้าม
กด **ADD** → **Upload file** → **With timing** → เลือก `subtitle_th_clean.srt`

> ซับช่วย 3 อย่างพร้อมกัน — คนดูแบบปิดเสียงเข้าใจได้ · YouTube อ่านเนื้อหาคลิปได้ทำให้แนะนำถูกกลุ่ม · และเป็นฐานให้แปลเป็นภาษาอื่นทีหลัง

### End screen
กด **ADD** → เลือกเทมเพลตที่มี **Subscribe** + **Best for viewer**

> วางในช่วง 20 วินาทีสุดท้าย แต่**ระวังอย่าให้ทับประโยคปิด** ของคุณจบที่ 10:08 ให้ end screen เริ่มประมาณ 9:48

### Cards
ข้ามไปก่อน ยังไม่มีคลิปอื่นให้ลิงก์

กด **NEXT**

# หน้าที่ 3 — Checks

รอระบบตรวจลิขสิทธิ์ ประมาณ 1-3 นาที

**ถ้าขึ้นเตือนเรื่องเพลง** แปลว่า BGM ที่ใช้มีเจ้าของ ให้กดดูรายละเอียด — ถ้าเป็นแบบ "ผู้ถือลิขสิทธิ์รับรายได้" ให้เปลี่ยนเพลงใหม่จาก YouTube Audio Library แล้วอัปคลิปใหม่ อย่าปล่อยผ่าน เพราะรายได้จะไปหาเจ้าของเพลงทั้งหมด

กด **NEXT**

# หน้าที่ 4 — Visibility

### แนะนำ: ตั้งเวลาโพสต์ ไม่ใช่กด Public ทันที

เลือก **Schedule** → ตั้งเป็น **วันเสาร์หรืออาทิตย์ เวลา 19:00–21:00** ตามเวลาไทย

> ช่วงนั้นคนไทยว่างและอยู่บนมือถือ คลิป 10 นาทีต้องการคนที่มีเวลานั่งดู ไม่ใช่คนที่เลื่อนผ่านตอนพักกลางวัน

ก่อนกด ให้เปิด **Premiere video** ด้วยถ้าอยากให้มีแชทสดตอนปล่อย — แต่คลิปแรกที่ยังไม่มีคนติดตาม อาจไม่มีใครมา ข้ามไปก่อนก็ได้

กด **SCHEDULE**

# หลังอัปเสร็จ

### 1. ดูตัวเองหนึ่งรอบเต็ม บนมือถือ

เปิดจากลิงก์ที่ได้ แล้วดูจนจบโดยไม่กดข้าม ตรวจ 4 อย่าง:
- เสียงดังพอเทียบกับคลิปอื่นในฟีดไหม
- ภาพเปลี่ยนตรงกับที่พูดไหม
- ซับขึ้นตรงเวลาไหม
- thumbnail อ่านออกตอนย่อเล็กไหม

### 2. Mid-roll — ยังตั้งไม่ได้ตอนนี้

แท็บ **Monetization** จะยังไม่ขึ้นจนกว่าจะผ่าน YPP

พอผ่านแล้วค่อยกลับมาที่คลิปนี้ → Monetization → ติ๊ก "Show mid-roll ads" → **MANAGE AD SLOTS** → ใส่ 3 จุดนี้:

```
3:46    6:17    7:45
```

### 3. กด Get notified

Studio → **Earn** → **Get notified**
YouTube จะอีเมลแจ้งทันทีที่ช่องถึงเกณฑ์ YPP
