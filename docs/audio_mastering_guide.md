# คู่มือทำเสียงเอง — CapCut + Audacity

เป้าหมาย: ทำให้เสียงคลิปคุณเทียบเท่าคลิปอ้างอิง

| | ตอนนี้ | เป้าหมาย |
|---|---|---|
| ความดัง | -23.7 LUFS | **-14 LUFS** |
| Loudness range | 5.5 LU | **2 – 3 LU** |
| Peak | -2.0 dBFS | ไม่เกิน -1.0 dBFS |
| BGM | ไม่มี | มี คลอตลอด |

---

## ⚠️ อ่านก่อน — ข้อจำกัดของ CapCut

**CapCut ไม่มี compressor และ limiter จริง** ซึ่งเป็นสองตัวที่จำเป็นที่สุด

และปุ่ม **Normalize Loudness ของ CapCut เล็งไปที่ประมาณ -23 LUFS** ซึ่งเป็นจุดที่ไฟล์คุณอยู่แล้วพอดี — กดไปก็แทบไม่เปลี่ยนอะไร

**แล้วทำไมไม่แค่ลากปุ่ม volume ขึ้น?** เพราะเลขไม่ยอม ไฟล์คุณ peak อยู่ที่ -2.0 dBFS การจะขึ้นจาก -23.7 ไป -14 LUFS ต้องเพิ่ม 9.7 dB ซึ่งจะดัน peak ไปที่ +7.7 dBFS = **เสียงแตกทั้งคลิป**

ต้องบีบอัดยอดคลื่นลงก่อน ถึงจะดันความดังรวมขึ้นได้ — และนั่นคืองานของ compressor

**สรุป:** ทำเสียงพูดใน Audacity (ฟรี) แล้วค่อยเอาไฟล์เข้า CapCut ไปทำ BGM กับตัดต่อ

# ส่วนที่ 1 — Audacity (ทำครั้งเดียว ~5 นาที)

ดาวน์โหลดฟรีที่ audacityteam.org

### 1. เปิดไฟล์
File → Open → `ElevenLabs_sound_trimmed.mp3`

### 2. Compressor
**Effect → Volume and Compression → Compressor**

| ค่า | ตั้งเป็น |
|---|---|
| Threshold | **-18 dB** |
| Noise Floor | -40 dB |
| Ratio | **3 : 1** |
| Attack Time | 0.10 s |
| Release Time | 1.0 s |
| Make-up gain for 0 dB after compressing | ✅ ติ๊ก |

กด Apply

> Threshold คือระดับที่เริ่มบีบ · Ratio 3:1 คือเสียงที่เกิน threshold ไป 3 dB จะถูกกดให้เหลือ 1 dB · ผลคือคำที่เบากับคำที่ดังเข้ามาใกล้กัน = LRA ลดลง

### 3. Loudness Normalization
**Effect → Volume and Compression → Loudness Normalization**

| ค่า | ตั้งเป็น |
|---|---|
| Normalize | **Perceived Loudness** |
| to | **-14 LUFS** |
| Treat mono as dual-mono | ✅ |

กด Apply

### 4. Limiter (กันแตก)
**Effect → Volume and Compression → Limiter**

| ค่า | ตั้งเป็น |
|---|---|
| Type | **Hard Limit** |
| Limit to (dB) | **-1.0** |
| Hold (ms) | 10 |
| Apply Make-up Gain | No |

กด Apply

### 5. Export
File → Export Audio → เลือก **WAV 16-bit** (ไม่ใช่ MP3 เพราะยังต้องเอาไปตัดต่อต่อ)

ตั้งชื่อ `voice_mastered.wav`

# ส่วนที่ 2 — CapCut

### 1. ตั้งค่าโปรเจกต์
สร้างโปรเจกต์ใหม่ → ตั้ง **1920×1080** และ **24 fps** (ตรงกับคลิปอ้างอิง)

### 2. วางเสียงพูด
ลาก `voice_mastered.wav` ลงแทร็กเสียงที่ 1

**สำคัญ: อย่ากด Normalize Loudness** เพราะมันจะดึงกลับไป -23 LUFS ทำลายงานที่ทำมา

ที่แผง Audio ของคลิปนี้:
- Volume: **0 dB** (ไม่ต้องแตะ)
- Noise reduction: **ปิด** — เสียง AI ไม่มี noise อยู่แล้ว เปิดแล้วทำให้เสียงบางลงเปล่า ๆ
- Voice enhance: **ปิด** — Audacity จัดการไปแล้ว เปิดซ้ำจะทำให้เสียงแข็ง

### 3. วางภาพ
ลากทั้งโฟลเดอร์ `images_v3` เข้ามา — CapCut จะเรียงตามชื่อไฟล์ซึ่งเป็นเวลาพอดี

ตั้ง default duration ของภาพเป็น 2.5 วินาที แล้วไล่ปรับตาม Timecode Map

### 4. ใส่ BGM
โหลดเพลงจาก **YouTube Audio Library** (studio.youtube.com → Audio library) เลือกหมวด **Ambient / Cinematic** ที่ไม่มีเมโลดี้เด่นและไม่มีเสียงร้อง

ลากลงแทร็กเสียงที่ 2 ต่อกันให้ยาวคลุมทั้งคลิป

**ระดับเสียง:** ตั้ง volume ของแทร็กเพลงไว้ที่ **8 – 12%** (ประมาณ -20 ถึง -24 dB)

คลิปอ้างอิงใช้เพลงเบามาก จนแทบไม่รู้ตัวว่ามี — หน้าที่ของมันคืออุดช่องว่างไม่ให้เงียบสนิท ไม่ใช่ให้คนฟังเพลง

### 5. Ducking
ถ้าเวอร์ชันคุณมี **Auto Ducking** ให้เลือกแทร็กเพลง → เปิด Auto Ducking → ตั้งความแรงประมาณ 30-40%

ถ้าไม่มี ไม่ต้องทำอะไร — เพลงที่ 10% เบาพอที่จะไม่บังเสียงพูดอยู่แล้ว

### 6. Fade
- เพลง: fade in 2 วินาทีตอนเริ่ม · fade out 3 วินาทีตอนจบ
- เสียงพูด: ไม่ต้อง fade

### 7. Export
Resolution **1080p** · Frame rate **24** · Bitrate **Recommended** ขึ้นไป · Format MP4

# เช็คลิสต์ก่อน export

- [ ] ไม่ได้กด Normalize Loudness ทับเสียงพูด
- [ ] Noise reduction และ Voice enhance ปิดทั้งคู่
- [ ] เพลงอยู่ที่ 8–12% ไม่ใช่ 50%
- [ ] เพลงคลุมยาวตลอดคลิป ไม่มีช่วงที่เพลงหายไปเฉย ๆ
- [ ] ลองฟังด้วยหูฟังที่วอลุ่มปกติ แล้วเทียบกับคลิปอ้างอิงว่าดังพอ ๆ กันไหม

# ทำไมต้อง -14 LUFS

YouTube ปรับความดังคลิปที่ **ดังเกิน** ให้ลงมาที่ราว -14 LUFS แต่**ไม่ดันคลิปที่เบาให้ดังขึ้น**

แปลว่าคลิปที่ส่งไปที่ -23 LUFS จะเล่นเบากว่าคลิปอื่นในฟีดตลอดไป คนดูต้องเร่งเสียงเอง ซึ่งเป็นแรงเสียดทานเล็ก ๆ ที่ทำให้คนกดออก

ส่งไปที่ -14 พอดีคือจุดที่ไม่โดนหั่นและไม่เสียเปรียบใคร
