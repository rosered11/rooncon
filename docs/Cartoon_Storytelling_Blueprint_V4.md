# 1. กฎทอง 14 ข้อ

**กฎ 1 — Voice First, Image Second**
อัดเสียงให้เสร็จก่อนเสมอ ภาพมาทีหลัง เพราะ rhythm มาจากเสียง

**กฎ 2 — Style Bible Lock**
แปะ Style Bible ใน system/context ของ Flow ครั้งเดียว ใช้ตลอด session

**กฎ 3 — Character Lock (@ref tags)**
ทุกตัวละครต้องมี `@TAG` — agent อ้างชื่อนี้ทุก shot

**กฎ 4 — Filename = Timecode**
`HH_MM_SS.jpeg` เช่น `00_00_05.jpeg` = ปรากฏที่วินาทีที่ 5

**กฎ 5 — One Beat Per Image (2.5–2.8 วิ/ภาพ)**
⚠️ **แก้จาก V3:** ผมวัดคลิปอ้างอิงระดับมืออาชีพแล้ว ได้ **2.5 และ 2.7 วิ/ภาพ** และ **95% ของเฟรมเป็นภาพนิ่ง** — ยืนยันว่าสไลด์ตัดแข็งคือวิธีที่ถูกต้อง ไม่ต้องทำอนิเมชัน

**กฎ 6 — Hook ทุก 15–30 วินาที**
pattern interrupt กันคนเลื่อนผ่าน

**กฎ 7 — Text in Image: ALL CAPS English เท่านั้น**
ห้าม bake ข้อความไทย ภาษาไทยพิมพ์ทับตอนตัดต่อ

**กฎ 8 — Subtle Transitions**
cut อย่างเดียว fade เฉพาะเปลี่ยน chapter

**🆕 กฎ 9 — ห้ามให้ AI เขียน @tag ลงในภาพ**
> `NEVER render @tags, filenames, or shot numbers as visible text in the image`
>
> **บทเรียนจริง:** รอบแรก Flow เขียน `@you` `@ancestor` ลงบนภาพ **28 ใบจาก 221** ทั้งที่ไม่ได้สั่ง ต้องใส่กฎนี้ไว้บนสุดของ [RULES] และ**ยังต้องสแกนซ้ำหลัง gen อยู่ดี**

**🆕 กฎ 10 — เสียงต้องไปที่ -14 LUFS**
ElevenLabs ส่งไฟล์มาที่ **-23.5 LUFS เสมอ** ซึ่งเบากว่ามาตรฐาน YouTube 9 dB
YouTube หรี่คลิปที่ดังเกินลงมา แต่**ไม่ดันคลิปที่เบาให้ดังขึ้น** — ปล่อยไว้คือเสียเปรียบทุกคลิปตลอดไป

**🆕 กฎ 11 — Loudness range ต้องอยู่ที่ 2–3 LU**
คลิปอ้างอิงระดับมืออาชีพวัดได้ **1.9 และ 2.0 LU** ส่วนไฟล์ดิบจาก ElevenLabs อยู่ที่ 3.5–5.5
นี่คือความต่างระหว่าง "เสียงแน่นใกล้หู" กับ "เสียงลอย ๆ"

**🆕 กฎ 12 — ต้องมี BGM คลอตลอดทั้งคลิป**
คลิปอ้างอิงมีเวลาเงียบสนิทแค่ **2–4%** ส่วนคลิปที่ไม่ใส่ BGM มี 15–25%
ดนตรีที่ **8–12%** อุดช่องว่างไม่ให้เงียบ ทำให้คลิปไม่รู้สึกอืด — สำคัญกว่าการไปตัดช่วงหยุดให้สั้นลง

**🆕 กฎ 13 — คลิปต้องยาวเกิน 8 นาที**
ต่ำกว่า 8 นาทีใส่ mid-roll ไม่ได้ ซึ่งเป็นรายได้หลัก
คลิป 4:45 มีโฆษณาทำเงินจริง 1 ครั้งต่อวิว ส่วนคลิป 10 นาทีมี 4 ครั้ง

**🆕 กฎ 14 — วาง mid-roll บนลมหายใจ ก่อนประโยคที่เปิดช่องว่างความอยากรู้**
YouTube ระบุว่า ad slot บนจุดพักธรรมชาติมีโอกาสยิงโฆษณาจริงสูงกว่า
เลือกจุดที่ **เงียบยาว + อยู่ก่อนคำถามหรือคำว่า "แต่..."** คนดูจะทนดูโฆษณาเพราะอยากรู้ประโยคถัดไป

# 2. STEP-BY-STEP

## 🧬 CONTENT & SCRIPT DNA

- **Niche:** Human history, evolution, anthropology, psychology
- **Format:** 10–14 นาที บุรุษที่ 2 ("คุณ") ห้ามใช้ "เรา" หรือ "ผม/ฉัน"
- **Hook formula:** โมเมนต์ปัจจุบันที่คนเชื่อมโยงได้ → "แต่ความจริงแปลกกว่านั้นเยอะ" → reframe
- **Rhythm:** ประโยคสั้น. ประโยคสั้น. ประโยคยาวหนึ่งประโยค. ประโยคสั้น. คำถาม?
- **Arc:** Hook → Reframe → Deep Dive → Twist → Modern Mirror → ปิดด้วยประโยคที่ echo ประโยคเปิด
- **งานวิจัยจริง** อ้างอย่างน้อย 3 จุด
- 🆕 **ปิดด้วย "แล้วทำยังไงต่อ"** ก่อนย่อหน้าสุดท้าย — ให้คนดูได้อะไรกลับไปทำ ช่วย retention ท้ายคลิปและกระตุ้นคอมเมนต์

## STAGE 2 — เขียนสคริปต์

### 🆕 สูตรคำนวณความยาว (วัดจริงจากไฟล์ที่ผลิตแล้ว)

> **12.3 ตัวอักษรไทย (ไม่นับช่องว่าง) = 1 วินาที**

| ความยาวคลิป | จำนวนตัวอักษร |
|---|---|
| 8 นาที | ~5,900 |
| **10 นาที** | **~7,400** |
| 12 นาที | ~8,900 |

### 🆕 กฎเขียนสำหรับ ElevenLabs v3

**v3 ไม่รองรับ `<break time="1.0s">` แล้ว** (ใช้ได้เฉพาะ v2) ความยาวช่วงหยุดมาจาก 2 อย่างเท่านั้น:

| สิ่งที่เขียน | ผลกับเสียง |
|---|---|
| เว้นบรรทัดคู่ (ย่อหน้าใหม่) | หยุดยาว |
| `...` | หยุดสั้น |

**เป้าหมาย:** เว้นบรรทัดคู่ **15–20 จุดต่อคลิป** เฉพาะรอยต่อบทจริง ประโยคที่ต่อเนื่องกันให้อยู่ย่อหน้าเดียวกัน

> **บทเรียนจริง:** สคริปต์ที่มี 125 ย่อหน้าใน 7,000 ตัวอักษร ทำให้ ElevenLabs Studio ใส่ช่วงหยุดเฉลี่ย 0.60 วิ (เงียบ 25% ของคลิป) ฟังแล้วอืดมาก เป้าที่ดีคือ **0.35–0.40 วิ**

### 🆕 กฎภาษาไทยสำหรับ TTS

- **ตัวเลขเขียนเป็นตัวหนังสือ** — "สองพันสิบเจ็ด" ไม่ใช่ "2017" (ไม่งั้นจะได้ยิน "ทเวนตี้เซเว่นทีน")
- **ชื่อฝรั่งเขียนคำอ่านไทย** — "บาวไมสเตอร์" ไม่ใช่ "Baumeister"
- **หน่วยเขียนเต็ม** — "แปดสิบเปอร์เซ็นต์" ไม่ใช่ "80%"

### OUTPUT
ไฟล์ `.txt` narration ล้วน ไม่มี markdown ไม่มี stage direction

### ⚠️ ลิมิต 5,000 ตัวอักษร

ช่อง Text to Speech ธรรมดาจำกัด 5,000 ตัวอักษร สคริปต์ 10 นาที (~7,400) จึงต้องเลือก:

**ทาง A — ElevenLabs Studio** วางรวดเดียวได้ แต่ระวังช่วงหยุดยาวกว่าปกติ

**ทาง B — ซอย 2 ไฟล์** ตัดที่รอยต่อบทที่เป็นประโยคจบหมัด แล้วต่อใน Audacity:
```
Import ทั้ง 2 ไฟล์ → Ctrl+A
→ Tracks → Align Tracks → Align End to End
→ Tracks → Mix → Mix and Render
→ ลบช่วงเงียบตรงรอยต่อให้เหลือ 0.6–0.9 วิ
→ Export WAV
```
- gen ทั้งสองไฟล์ในเซสชันเดียว voice เดิม setting เดิม
- MP3 ทุกไฟล์มี encoder padding หัวท้าย 30–50 ms ต้องตัดออก
- **ต่อให้เสร็จก่อน แล้วค่อยทำ timecode** ห้ามถอด timecode แยกไฟล์แล้วบวกเลขเอง

## STAGE 4 — 🆕 มาสเตอร์เสียงใน Audacity

> **ElevenLabs ทำขั้นนี้ไม่ได้** ไม่มี compressor ไม่มี limiter ไม่มีที่ตั้ง LUFS ทุกแพลน

### 1. Compressor
**Effect → Volume and Compression → Compressor**

| | ถ้า LRA ดิบ > 4.5 (ทำ 2 รอบ) | ถ้า LRA ดิบ < 4 (รอบเดียว) |
|---|---|---|
| Threshold | รอบ 1: **-28** · รอบ 2: **-16** | **-22** |
| Ratio | รอบ 1: **5:1** · รอบ 2: **3:1** | **4:1** |
| Knee | 6 dB | 6 dB |
| Lookahead | 10 / 5 ms | 10 ms |
| Attack | 20 / 5 ms | 20 ms |
| Release | 250 / 120 ms | 250 ms |
| Make-up Gain | 0 | 0 |

> แยกสองชั้นเบา ๆ ได้ผลดีกว่าชั้นเดียวแรง ๆ — ชั้นเดียวได้ LRA 4.2 แต่สองชั้นได้ 2.7

### 2. Loudness Normalization
Perceived Loudness → **-14 LUFS** · Treat mono as dual-mono ✅

### 3. Limiter — **ต้องเป็นขั้นสุดท้ายเสมอ**
Threshold **-1.0 dB** · Make-up Gain **0** · Lookahead 10 ms · Release 50 ms

> ⚠️ **ห้ามใช้ Amplify แทน Limiter** Amplify ลดทั้งไฟล์เท่ากันหมด มันไม่รู้จักว่ายอดไหนต้องกดเป็นพิเศษ
>
> **บทเรียนจริง:** ข้ามขั้น Limiter แล้วใช้ Amplify แทน ผลคือได้ -17 LUFS แต่ true peak ยังทะลุ +0.29 dB → **แซมเปิลชนเพดาน 4,164 จุด** เสียงแตกถาวรในไฟล์

### 4. เช็คก่อน export
เปิด **Amplify** ดูค่าที่มันเติมมาให้ — ควรขึ้น **~1.0** แล้วกด **Cancel**
ถ้าติดลบ = peak ทะลุแล้ว ต้องกลับไปทำ Limiter ใหม่

### 5. Export
**WAV 16-bit 44.1 kHz** — ห้าม export เป็น MP3 จะกลายเป็นบีบอัดสองรอบ

### เป้าหมายที่ต้องได้

| | ค่า |
|---|---|
| Integrated loudness | **-14 ถึง -16 LUFS** |
| Loudness range | **2–3 LU** |
| True peak | **ไม่เกิน -1.0 dBFS** |
| แซมเปิลที่ชนเพดาน | **0** |

## STAGE 5 — ⚠️ Timecode Map

**V3 บอกให้ผู้ใช้ฟังแล้วพิมพ์ timestamp เอง — ไม่ต้องแล้ว**

### ขั้นที่ 1 — ถอด SRT ด้วย SayToWords

อัปโหลด **ไฟล์เสียงที่มาสเตอร์เสร็จแล้ว** (ไฟล์เดียว ต่อสมบูรณ์แล้ว) → ดาวน์โหลด SRT

> **ต่อไฟล์ให้เสร็จก่อนเสมอ** ห้ามถอด SRT แยกสองไฟล์แล้วเอาเวลามาบวกกันเอง เพราะจะคลาดกับไฟล์จริงที่เอาไปตัด แล้วภาพจะเลื่อนทั้งคลิป

### ขั้นที่ 2 — ส่งให้ Claude 2 อย่าง

1. **ไฟล์ SRT** → ใช้เฉพาะ **ตัวเลขเวลา**
2. **สคริปต์ต้นฉบับ .txt** → ใช้เป็น **ตัวหนังสือ**

### ⚠️ กฎสำคัญ: ห้ามใช้ข้อความจาก SRT

SayToWords เป็น ASR — มันฟังแล้วเดาว่าพูดอะไร ซึ่งเพี้ยนเสมอกับภาษาไทย

| SRT เขียนว่า | ที่ถูกคือ |
|---|---|
| เสกกระจก | เศษกระจก |
| ทุ่งย่า | ทุ่งหญ้า |
| ความเสื่อ | ความเสือก |
| นับภาษาวิทยา | นักประสาทวิทยา |
| ขวางเล่นของคุณ | ขวางเลนของคุณ |
| สิ่งกิดขวาง | สิ่งกีดขวาง |

**เวลาจาก SRT แม่น · ข้อความจาก SRT ไม่แม่น**

Claude จะจับคู่ประโยคในสคริปต์ต้นฉบับเข้ากับช่วงเวลาใน SRT ตามลำดับ ทำให้ได้ตารางที่เวลาถูกและตัวหนังสือถูกพร้อมกัน

### ทางเลือกสำรอง — ไม่มี SRT ก็ได้

ส่ง**ไฟล์เสียงเปล่า ๆ** ให้ Claude ก็ได้ Claude ตรวจจับช่วงหยุดหายใจจากคลื่นเสียงโดยตรง (silence detect) แล้วจับคู่กับสคริปต์ตามสัดส่วน — ไม่ต้องผ่าน ASR เลย แต่ขอบประโยคจะหยาบกว่าใช้ SRT เล็กน้อย

### 🆕 สูตรจำนวนช็อต

```
จำนวนช็อต = ความยาวคลิป (วินาที) ÷ 2.6
```
คลิป 10 นาที ≈ **230 ช็อต**

**ถ้าต้องการใช้ภาพชุดเดิมซ้ำ** บอก Claude ให้ล็อกจำนวนช็อตเท่าเดิม แล้วปรับความยาวเฉลี่ยแทน — ภาพทุกใบยังใช้ได้ เปลี่ยนแค่ชื่อไฟล์

| มุมมอง | แบนล้วน | **มี isometric สำหรับสิ่งปลูกสร้าง** |
| ข้อความ | ALL CAPS แดง/เหลือง บนหัวเฟรม | **ดำเป็นหลัก ขนาดต่างกันมาก แดงเฉพาะตัวเลข** |

พาเลตต์ที่สุ่มค่าจริงจากคลิปอ้างอิง:
`#FCFCFC` `#B4E4CC` `#E4CC9C` `#B4E4E4` `#9CCCE4` `#549C54` `#B46C54` `#E46C24` `#846CCC` `#9C6C3C` `#CCCCCC` `#9C9C9C` `#6C6C6C` · accent `#D94040`

### [RULES] ที่ต้องมีทุกครั้ง

```
- Keep character appearance IDENTICAL across all shots
- Use the EXACT filename given for each shot
- NEVER render @tags, filenames, or shot numbers as visible text in the image
- On-screen text allowed ONLY where written in the shot line, ALL CAPS English
- Aspect ratio 16:9 for ALL images, highest resolution available
- Apply STYLE BIBLE to every single image
- Muted palette only — no saturated primaries, no thick marker lines
```

## STAGE 8 — ตัดต่อ

**ตั้งโปรเจกต์:** 1920×1080 · **24 fps** (ตรงกับคลิปอ้างอิง ให้ความรู้สึกสารคดี)

**เสียงพูด:** ลากไฟล์ที่มาสเตอร์แล้วเข้าไป **แล้วอย่าแตะอะไรทั้งนั้น**
- ❌ ห้ามกด Normalize Loudness (CapCut เล็งที่ -23 LUFS จะดึงกลับ)
- ❌ ปิด Noise reduction (เสียง AI ไม่มี noise)
- ❌ ปิด Voice enhance (มาสเตอร์ไปแล้ว)

**BGM:** YouTube Audio Library หมวด Ambient/Cinematic ไม่มีเมโลดี้เด่น ไม่มีเสียงร้อง
ตั้งไว้ที่ **8–12%** · fade in 2 วิ · fade out 3 วิ · คลุมยาวตลอดคลิป

**ภาพ:** ลากทั้งโฟลเดอร์ CapCut เรียงตามชื่อไฟล์ซึ่งเป็นเวลาพอดี

- ถ้ามีลายน้ำโผล่มา **ห้ามครอปทิ้ง** ให้อัปเกรดแทน

**นโยบาย inauthentic content ของ YouTube:**
